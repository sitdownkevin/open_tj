Open TJ Android 0.2.1 预览版，支持 Android 8.0（API 26）及以上。

## 下载与安装

1. 下载附件 `OpenTJ-0.2.1-android.apk`，在手机上打开并完成系统安装提示。
2. 输入自己的同济校园 VPN 账号与密码，点击「连接校园网络」。
3. 同意 Android VPN 授权；可按需允许连接状态通知。

无需电脑、ADB、JDK 或其他客户端；不要下载源码 ZIP 来安装。
`.apk.sha256` 用于校验文件完整性，`release-certificate.sha256` 为公开签名证书指纹。

## 功能与验证

- 原生连接界面、通知栏断开、流量统计、内存日志及可选加密保存密码。
- Wi-Fi / 移动数据切换和临时断线自动重连。
- IPv4 全局隧道；连接期间阻断 IPv6。
- 在 vivo X200 Pro / Android 16 上验证了认证、DNS、HTTP、主动断开及网络切换。
- 此 APK 由 GitHub Actions 构建并使用固定密钥签名；发布前在 Android 8 / 16
  模拟器验证优化版本的安装、冷启动和重复覆盖安装。

## 升级与限制

后续 GitHub Release APK 使用相同签名，可直接覆盖升级并保留应用数据。
早期通过 ADB 安装的 debug 开发包与此包签名不同，不能直接覆盖；
迁移前请确认已保存账号信息，不要为解决签名提示而直接清空应用数据。

本版仍为预览版：30 分钟以上锁屏后台连接和更多厂商设备尚未完成验收。
断线重连期间会释放 VPN 接口，不提供始终开启 VPN、lockdown 或跨重连的 kill switch。
账号与 VPN 授权由使用者自行提供，安装包不含校园账号或服务器访问权限。
